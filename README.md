# AWS Hybrid Infrastructure Lab

Laboratório de infraestrutura AWS desenvolvido com Terraform.

## Objetivo

Simular uma infraestrutura corporativa utilizando boas práticas de:

- Networking
- Segurança
- Infrastructure as Code
- Monitoramento
- Alta disponibilidade
- Integração híbrida

## Tecnologias

- AWS
- Terraform
- Linux
- Nginx
- CloudWatch
- GitHub Actions
